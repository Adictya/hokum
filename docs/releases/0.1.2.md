Update checks.

- The running service checks for a new build a minute after it starts and
  then hourly, fetching its channel's release manifest as
  `hokum/<channel>/<version>` (#6).
- When a different build is out, one Hokum card offers it. A plain install
  you can write (`~/.local/bin/hokum`) updates with a click: Hokum downloads
  the new executable, checks its size and sha256, replaces itself and
  restarts. Installs from the AUR, .deb or .rpm get their package manager's
  update command copied instead. Nothing installs without a click (#7, #8).
- New command: `hokum update` checks now, and `hokum update --install` does
  what the card's button does (#7).
- Set `check-for-updates #false` in `behaviour` in `config.kdl` to turn the
  checks off.
